# Day 1 项目骨架、认证与权限底座

## 技术栈

- Monorepo：npm workspaces
- 后端：Express 5 + TypeScript + JWT + Vitest + Supertest
- 前端：React + Vite + React Router + TypeScript + Vitest
- 共享类型：`packages/shared`

## 职能负责人

当前 demo 负责人，每个职能支持多个负责人：

| 职能 | 负责人 |
| --- | --- |
| 平台研发部 | `10002` |
| 产品部 | `10001` |
| 项目管理部 | `10001` |
| 质量保障部 | `10001` |
| 体验设计部 | `10001` |
| 运营客服部 | `10001` |
| 专项评审组 | `10001` |
| 管理层 | `10001` |

负责人登录后可进入“职能成员”管理本职能账号；`admin` 可管理全部职能，并可将某个职能成员追加为负责人或移除负责人身份。每个职能至少保留一名负责人。

## 本地启动


- Web：http://localhost:5173
- API：http://localhost:3000/api/v1
